# 주차장 탈출

꽉 막힌 주차장에서 차를 하나씩 빼내는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 차를 누르면 앞으로(앞유리·화살표 쪽) 달린다. 앞길이 판 끝까지 비어 있으면 빠져나가고, 막혀 있으면 앞차에 쾅 부딪혀 제자리로 돌아온다
- 차를 모두 빼면 클리어. 한 번도 안 부딪히면 별 3개, 1번이면 2개, 그 이상은 1개
- 주차장은 4레벨마다 넓어지고(5×5 → 8×8), 3레벨부터 3칸짜리 트럭, 6레벨부터 고깔(장애물)이 나온다
- 판은 매번 새로 만든다. 빽빽하게 채운 뒤 서로 막는 순환이 없어질 때까지 차를 돌려서, 항상 풀 수 있는 판만 낸다
- 힌트는 한 판에 3번: 지금 뺄 수 있는 차 중 다른 차를 가장 많이 막고 있는 차를 알려 준다
- 진행한 레벨은 브라우저에 저장된다

`index.html` 을 그대로 열면 된다. 규칙·판 만들기는 `logic.js`, 화면·입력은 `game.js`.
